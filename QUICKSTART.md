# Web OS - Quick Start Guide

## Windows Users
1. Download the ZIP file
2. Extract it
3. **Double-click `run.bat`**
4. Wait for the browser to open automatically
5. Create an account and login

## Mac/Linux Users
1. Download the ZIP file
2. Extract it
3. Open Terminal
4. Type: `chmod +x run.sh && ./run.sh`
5. Wait for the browser to open automatically
6. Create an account and login

## That's it!
The app will install dependencies and start automatically.

## First Time Setup
- Create a username
- Enter an email
- Set a password
- Click "Create New Account"
- Then login with your credentials

## Features
- 💬 Messaging - Chat with other users in real-time
- 📁 File System - Create and manage files
- 💻 Code Editor - Write and run JavaScript code
- 🎮 Games - Play multiplayer games
- 🛍️ App Store - Browse and install apps
- 🖥️ Desktop Environment - Drag windows, open apps

## Troubleshooting
If it doesn't work:
- Make sure Python 3.8+ is installed on your computer
- Close the terminal and try again
- Restart your computer and try again
